MODELING DATASET SCHEMA
=======================

File produced by:
  scripts/build_conus404_outage_dataset.py

Primary modeling file:
  all_counties_classified_stat_all_days_conus404_4class_p80.csv

Rows
----
One row per Florida county-day. The build script keeps days without usable
EAGLE-I observations and marks them with outage_data_available = 0. Those rows
may be predicted by the model but are not used for training or evaluation.

Target classes
--------------
duration = 0 : no weather-related outage
duration = 1 : minor, 1 <= outage duration < 2 h
duration = 2 : moderate, 2 <= outage duration < 8 h
duration = 3 : major, outage duration >= 8 h

Weather-related filter
----------------------
The current public script uses county-specific 80th-percentile thresholds for:
  WSPD10_cellmax_dmax
  PREC_ACC_NC_cellmean_dsum
An outage is retained as weather-related when either variable exceeds its
county threshold on the outage day or the preceding day.
