LEGACY / OPTIONAL PLOTTING SCRIPTS
=================================

The scripts in this folder are retained for provenance only. They are not
required for the final manuscript figure workflow.

Recommended replacement:
  ../scripts/make_publication_figures.py

Files
-----
make_temporal_spatial_tradeoff.py
  Earlier standalone temporal-vs-spatial trade-off implementation.

plot_annual_and_spatial.py
  Earlier standalone annual and spatial plotting implementation.

publication_style.py
  Style helper from earlier plotting variants.

Keeping these files separate prevents duplicate figure workflows from being
mistaken for required dependencies.
